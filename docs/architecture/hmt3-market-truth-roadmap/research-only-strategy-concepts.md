# HMT-3 — Research-Only / Strategy-Only Concepts

**Initiative:** `HMT-3 — Post-HMT-2 HERMES Market Truth Roadmap`
**Status:** DOCUMENTATION / GOVERNANCE RECORD ONLY. Governs every HMT-3 item. See
[`hmt3-roadmap-overview.md`](hmt3-roadmap-overview.md) for the roadmap-wide non-authorisation statement.

## Purpose

Name, in full, the concepts that belong to DARWIN and, only after evidence, to HSA/HELIOS — and never to
HERMES — so that no HMT-3 item mistakenly treats one of them as a market-truth fact.

## §1 — The list

The following are research-only or strategy-only concepts:

- Wick-versus-close stop rules.
- Catastrophic stop placement.
- First-touch preference.
- Confluence-is-better assumptions.
- TP/SL decisions.
- Entry/exit decisions.
- Horizon-specific strategy weighting.

## §2 — Ownership

> These belong to DARWIN and, only after evidence, HSA/HELIOS.

None of the concepts in §1 is produced, decided, or endorsed by HERMES at any point in this roadmap.
HERMES's role, per the governing system separation restated in
[`hmt3-roadmap-overview.md`](hmt3-roadmap-overview.md), is limited to measuring the reproducible facts
(e.g. the level-interaction and structural-geometry facts in
[HMT-3D](hmt3d-structural-price-geography.md) and [HMT-3E](hmt3e-level-interaction-state.md)) that DARWIN
may later draw on when it investigates whether any of these strategy-only concepts is actually supported
by evidence. HMT-3E §2's prohibition on baking in a "first touch is superior" assumption is a specific
instance of this same boundary.

## §3 — Non-authorisation

This document states doctrine that governs every HMT-3 item's scope boundary with DARWIN/HSA/HELIOS. It
does not itself authorise any implementation. See [`hmt3-roadmap-overview.md`](hmt3-roadmap-overview.md).
