# HMT-3I — Objective Gap Geometry

**Initiative:** `HMT-3 — Post-HMT-2 HERMES Market Truth Roadmap`
**Status:** **NOT YET AUTHORISED FOR IMPLEMENTATION.** See
[`hmt3-roadmap-overview.md`](hmt3-roadmap-overview.md).

## Purpose

Name the objective gap-geometry fact family, note its low priority within this roadmap, and state the
terminology boundary and DARWIN-deferred value question that govern it.

## §1 — Priority

This item is **low priority** within the HMT-3 roadmap, relative to HMT-3A through HMT-3H.

## §2 — Fact family

Deterministic three-candle non-overlap geometry and lifecycle facts — i.e. objective, deterministically
detected price-gap geometry between three candles, and the lifecycle facts describing what subsequently
happens to that geometry (e.g. whether and when it is filled).

## §3 — No institutional/"smart money" semantics

This item's facts must be produced and published **without** institutional or "smart money" semantics —
"fair value gap," "institutional gap," or any similarly interpretive label is not a permitted fact identity
here. The geometry is published as objective geometry; see
[`terminology-doctrine.md`](terminology-doctrine.md) for the general rule this specific instance falls
under.

## §4 — DARWIN determines whether this geometry adds incremental information

Whether this objectively-detected gap geometry adds any incremental information of value is not decided by
this item or this document:

> DARWIN determines whether this geometry adds incremental information.

implementation of it. See [`hmt3-roadmap-overview.md`](hmt3-roadmap-overview.md) for the programme-wide
