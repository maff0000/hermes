# Ownership Classification — Candle Features
HERMES-OWNED deterministic (this WO's contract scope): body_size, range_size, wick_high/low, body_high/low,
candle_direction, body_to_range_ratio, upper/lower wick ratios, close_position_in_range, and THRESHOLD-DEFINED
deterministic flags doji/full_body/long_wick/pin_bar/inside_bar/outside_bar/engulfing (governed config thresholds).
ARES-OWNED / REJECTED: regime labels, risk interpretation, liquidity intent, smart-money interpretation, order-block
meaning, trade signal/decision, go/no-go, confidence-as-trade/risk-assertion. The validator REJECTS these as field keys.
OWNERSHIP-PENDING: deterministic sessions/levels are HERMES-owned but tracked as separate future families.
